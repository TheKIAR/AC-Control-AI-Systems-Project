# Archive — moved out of the way, kept for reference

This folder holds files that were cluttering the project root but were not
deleted, just in case they are ever needed.

- `scaffolding/` — placeholder files from the initial project template
  (blank `models/*` stubs and `data/*` readme notes). Nothing in `src/`,
  `tests/` or `scripts/` ever read them; the data pipeline generates its
  data synthetically at runtime. Kept here with history
  (`git log --follow`) instead of in the live tree.
- `evidence-2026-09/` — stale sample outputs (charts, summaries, one report
  zip) generated by earlier probe runs. The GUI `Export` button regenerates
  fresh evidence into `outputs/` on demand, so these copies are frozen here.
