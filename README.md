## 👋 What is this?
A hands-on Python AI project exploring four complementary approaches to intelligent room control.

| System | Role |
|---|---|
| 🌡️ Fuzzy Logic | Temperature reasoning |
| 🧠 FOPL | Explainable smart-room reasoning |
| 🎯 Reinforcement Learning | Q-table learning in a small environment |
| 📊 Data Pipeline | Deterministic data generation and processing |

## ✨ Highlights
- 🎨 Dark/light GUI themes and animated weather visuals
- 💡 Live FOPL policy LEDs and room switches
- ⚡ Auto Mode for responsive AI pipeline updates
- 📈 RL reward statistics and charts
- 🧩 Explainable inference traces
- 📦 Exportable charts, summaries and logic traces
- 🧪 Automated tests with GitHub Actions

## 🔄 AI Pipeline
**Temperature → Fuzzy Logic → FOPL Room Policy → Reinforcement Learning → Data Pipeline → Integrated Result**

## 🧠 How it works
**Fuzzy Logic:** maps Cold / Comfortable / Hot conditions to control actions.

**FOPL:** combines temperature, occupancy, night and energy-saver facts to derive explainable room-control decisions.

**Reinforcement Learning:** uses a compact Q-table agent, environment and trainer with retained rewards for evaluation.

**Data Processing:** generates, cleans, transforms and serializes structured examples.

## 🚀 Run locally
**Requirements:** Python 3.11+, Tkinter and requirements.txt dependencies.

    python -m pip install -r requirements.txt
    python run_gui.py

Console mode:

    python run_gui.py --console

Tests:

    pytest
