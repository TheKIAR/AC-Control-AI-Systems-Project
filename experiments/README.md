# Experiments Documentation

This README file provides an overview of the experiments conducted in the AI Systems Project, focusing on three main areas: Fuzzy Logic, Reinforcement Learning, and Data-Driven Methods.

## 1. Fuzzy Logic Experiments

The fuzzy logic experiments aim to evaluate the performance of the FuzzySystem implemented in the `src/fuzzy_logic` module. The experiments include:

- **System Evaluation**: Testing the effectiveness of the fuzzy logic control system in managing air conditioning settings based on various input parameters.
- **Rule Testing**: Assessing the impact of different fuzzy rules defined in the `rules.py` file on system performance.

Results and findings from these experiments can be found in the `notebooks/fuzzy_experiments.ipynb`.

## 2. Reinforcement Learning Experiments

The reinforcement learning experiments focus on training and evaluating the RLAgent within the `src/reinforcement_learning` module. Key aspects include:

- **Agent Training**: Running simulations to train the RLAgent using various strategies and reward structures.
- **Performance Metrics**: Analyzing the agent's learning curve and decision-making capabilities in the simulated environment.

Detailed results and analysis are documented in the `notebooks/rl_experiments.ipynb`.

## 3. Data-Driven Method Experiments

The data-driven experiments explore the effectiveness of the DataGenerator and the associated pipeline for generating and processing data. This includes:

- **Data Generation Techniques**: Evaluating different methods for generating synthetic data and their applicability to the AI systems.
- **Data Processing**: Assessing the efficiency of the data cleaning and transformation processes implemented in the `pipeline.py`.

Findings from these experiments are available in the `notebooks/data_generation.ipynb`.

## Conclusion

This document serves as a guide to the experiments conducted in the AI Systems Project. For detailed methodologies, results, and future work, please refer to the respective Jupyter notebooks.
